# SW CANS Website

Official website for SW CANS - Monster Energy Can Collectors and Resellers.

## Description

This website serves as a hub for Monster Energy can collectors and enthusiasts. It features:
- Social media links
- Marketplace connections
- Upcoming collection management tool
- About section

## Setup

This is a static website that can be served directly from GitHub Pages. The site is built with:
- HTML5
- CSS3
- JavaScript
- Font Awesome icons

## Development

To run this site locally:
1. Clone the repository
2. Open `index.html` in your browser

## Deployment

The site is automatically deployed through GitHub Pages when pushing to the main branch.
